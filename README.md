## 🚀 Featured Engineering Projects

### 1. Self-Powered Autonomous Hydro-Valve System
**Discipline:** Electromechanical Systems, Kinetic Energy Harvesting & Subterranean Telemetry  
**Core Technologies:** Heltec ESP32 LoRa 32 (V4), MP1584EN Buck Converter, TPS61088 Synchronous Boost, 12V Motorized Ball Valve, SolidWorks  

* **Core Innovation:** Engineered an autonomous, zero-maintenance valve system eliminating underground power trenching by harvesting fluid flow kinetic energy via an in-line micro-hydro generator into a 3.7V LiPo buffer[cite: 6].
* **Subterranean RF Control:** Implemented sub-GHz LoRa with Channel Activity Detection (CAD) deep-sleep cycling (~15 µA standby) for ground/pit signal penetration[cite: 6, 8].
* **Dual-Rail Power Architecture:** Synchronously stepped 3.7V battery voltage up to 12V to handle peak 2.5A motor breakaway inrush without logic brownouts, backed by 1N5819 Schottky reverse-current isolation[cite: 6, 8].

### 3. 3D-Printed Functional Prosthetic Hand
**Discipline:** Biomechatronics, Rapid Prototyping & Mechanism Design  
**Core Technologies:** SolidWorks, PLA Additive Manufacturing, Micro-Servo Actuation, Tendon Cable Routing, Arduino Nano  

* **Accessible Mechanical Architecture:** Designed an articulated upper-limb prosthetic hand under $30 manufacturing cost and 1.50 lbs total mass[cite: 12].
* **Anatomical Tendon Grasp:** Engineered modular 3-segment digits actuated via routed nylon tendon lines and elastic return bands, achieving a rapid 1.0-second full closure and 370 g payload hold[cite: 12, 13].
* **Iterative Problem Solving:** Overcame joint binding by engineering custom compressible snap-fit pins, chamfering internal routing paths to minimize tendon friction, and offsetting thumb geometry for true opposition grasp[cite: 13].
